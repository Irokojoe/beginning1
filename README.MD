# Python Practice

Small beginner Python scripts I wrote while learning.

## Files

- `password_generator.py`: generates a random 10-character password every 5 seconds.
- `account_system.py`: a simple sign-in and account-creation program using a dictionary.

## How to run

python password_generator.py
python account_system.py

## Notes

This is a learning project. Accounts are not saved after the program closes, and passwords are stored as plain text. I plan to improve this.
